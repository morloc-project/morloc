# Known issues

Each file holds a group of related issues, each framed against the model:
a spec item the code violates, or a gap in the spec. Evidence levels:
reproduced, read (verified by reading), speculative. Delete an entry when
it is solved, and a file when it is empty.

- [failure-classification.md](failure-classification.md): a reply wait that watches the listener, not the worker; C++ failures still thrown as std::runtime_error, queued requests closed unanswered at shutdown (DAEMON-6), NET-5 vs DAEMON-6, refusal classes, PANIC-4 exceptions
- [wire-bounds.md](wire-bounds.md): unchecked lengths and offsets in packets, stream files and allocation sizes
- [shared-memory.md](shared-memory.md): stale topology.md text, C++ trackers on helper threads never flush, a speculative RecoverableLock race, FORK-15 staging failure; the block census counts only mapped volumes; an allocation that misses its cursor walks the volume; argument blocks outside an eval arena never freed; SHM-15 unchecked for pool-sent values; a pure command cannot @load a table; a view registered during a fork keeps its references (FORK-15)
- [value-encoding.md](value-encoding.md): R U64 type map (numeric) disagrees with its codec (integer64); missing record keys, MessagePack decoder bugs, record alignment, Map vs Tuple alignment, canonical bytes; Python and R `F32` scalars lose signalling NaNs (WIRE-7); multi-limb Int overflow messages omit the value (WIRE-3), Python Bool read through `*(bool*)` (WIRE-8); no recursive packers, so a recursive type with a packed value is refused
- [cache.md](cache.md): keys miss files the sourced files import, pools find sourced files by search rather than by the hashed path, an installed program built from outside its package cannot find its sourced files, unverified keys, log and summary leaks into nested runs
- [cli-directives.md](cli-directives.md): cross-language @fold, @render type check and -f, multi-output gaps
- [mcp.md](mcp.md): streaming calls refused off the CLI, MCP stdio server in one-shot mode, front-end line cap checked after copying; DAEMON-15 checked by path, not by file, unknown query keys ignored; IPv6 bind address, eval waiver `=0`, `/call` reaches MCP-excluded commands, 401/OPTIONS drift, cancel ignored, `GET /eval` 405, `__` collision aborts
- [nexus-cli.md](nexus-cli.md): `-f mpk` output sniffed when read back; `view --pattern` side defects (empty -o file on failure, nested groups); `-f voidstar` of a table writes a reference; output-path errmsg and empty-packet defects; partial stream output; argument files read by extension before bytes (CLI-1), `-f packet` of a top-level null writes nothing (CLI-5), two default layouts in help
- [tables-tensors.md](tables-tensors.md): sampled column types, unchecked tensor dims (DIM-3), TAB-1/5/6 gaps, CLI-20 cell-error timing
