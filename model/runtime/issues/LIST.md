# Known issues

Each file holds a group of related issues, each framed against the model:
a spec item the code violates, or a gap in the spec. Evidence levels:
reproduced, read (verified by reading), speculative. Delete an entry when
it is solved, and a file when it is empty.

- [failure-classification.md](failure-classification.md): misclassified failures (peer death exits 70) and unbounded or bounded waits; a catch-all still holds a closed pipe (PANIC-13), C++ failures still thrown as std::runtime_error, queued requests closed unanswered at shutdown (DAEMON-6), NET-5 vs DAEMON-6, refusal classes, PANIC-4 exceptions; a C++ `@read` failure does not name its input
- [wire-bounds.md](wire-bounds.md): unchecked lengths and offsets in packets, stream files and allocation sizes
- [shared-memory.md](shared-memory.md): stale spec text, C++ trackers on helper threads never flush, a speculative RecoverableLock race, FORK-15 staging failure; the block census counts only mapped volumes; an allocation that misses its cursor walks the volume; argument blocks outside an eval arena never freed; SHM-15 unchecked for pool-sent values; a pure command cannot @load a table; a view registered during a fork keeps its references (FORK-15)
- [value-encoding.md](value-encoding.md): R U64 type map (numeric) disagrees with its codec (integer64); missing record keys, MessagePack decoder bugs, record alignment, Map vs Tuple alignment, canonical bytes; Python and R `F32` scalars lose signalling NaNs (WIRE-7); multi-limb Int overflow messages omit the value (WIRE-3), Python Bool read through `*(bool*)` (WIRE-8)
- [cache.md](cache.md): keys miss files the sourced files import, unverified keys, log and summary leaks into nested runs
- [cli-directives.md](cli-directives.md): cross-language @fold, @render type check and -f, multi-output gaps
- [mcp.md](mcp.md): streaming calls refused off the CLI, MCP stdio server in one-shot mode, front-end line cap checked after copying; DAEMON-15 checked by path, not by file, HTTP path truncated at 255 bytes
- [nexus-cli.md](nexus-cli.md): `-f mpk` output sniffed when read back; `view --pattern` side defects (empty -o file on failure, nested groups); `-f voidstar` of a table writes a reference; output-path errmsg and empty-packet defects; partial stream output; argument files read by extension before bytes (CLI-1), `-f packet` of a top-level null writes nothing (CLI-5), two default layouts in help
- [tables-tensors.md](tables-tensors.md): column type inference, NaN in JSON, tensor dims unchecked, table spec mismatches
- [build-and-text.md](build-and-text.md): non-atomic build swap, a killed build's staging tree never removed, stale help text and comments, dead code, morloc.h expression structs drifted from Rust; ABI version never gated, crate versions out of lockstep, mlcKind/morloc.h untested; a pool's newer crate pins dropped from the environment lock, which keeps a table per program; a native type form does not bring in its defining file (needs a ruling); sourced files identified loosely (lossy Python binding names, Rust dedup before canonicalizing); `morloc init` succeeds when the C++ shim fails to compile; a refused rebuild leaves its staging tree (ART-2), a failed owner record leaks an unsweepable run dir; two runtime-type copies across an allocator change, manifest strings never freed
- [streams.md](streams.md): written streams: nexus stdout lock, open questions on deferred completion, dead openers, stdout placement, @tell, reopen after a daemon call; measured speedups (nested element append, stdin read-ahead); a forked child inherits its parent's cache byte count; slots may decode one offset ahead twice after a reset; the per-process queue bound (SLOT-32) wakes late, has no setting, and is not host-wide; every daemon call sweeps the whole registry; per-operation scans over growing slot, cell, temp-file and view lists; SLOT-28 PAUSED sources misstated, idle slots capped at 16 (SLOT-23), corrupt footer silently scanned (SLOT-29)
- [alignment.md](alignment.md): 64-byte numeric array alignment not delivered on every path; guarantee or preference, and for which sizes (deferred); C++ reads wire fields at addresses not even naturally aligned (UB, reproduced under UBSan)
- [kept-connections.md](kept-connections.md): kept caller connections into Python and R fork pools; affinity deadlock, options (deferred)
- [flaky-tests.md](flaky-tests.md): intermittent test failures with no known cause; the integration suite deletes every morloc run's shm and tmp dirs; a nexus waits forever when its run dir is deleted; a forked test child blocks on a lock held at fork; bare-forked children hold other tests' descriptors; a rare full-run hang
- [pools-and-ipc.md](pools-and-ipc.md): pool readiness latency, per-pid sweep race, R close-on-exec, C++ path truncation; macOS sockets not close-on-exec from birth; a socket made across a fork stays open in the child; 55 ms fixed cost of a one-pool program (/tmp scan, connect backoff, custody sleep at exit); host state not shared across fork-pool workers (stream-r sorters)
- [remote-dispatch.md](remote-dispatch.md): SLURM jobs: inherited parent environment, endless poll on empty sacct, job directories left by a killed parent
- [rust-closures-threads.md](rust-closures-threads.md): function values on callback threads: host panics end the pool, late calls unspecified, refcount contention, boxed direct closures; opaque capture front-end error
- [encode-throughput.md](encode-throughput.md): perf: stream decode copies every field (slower than parsing the text), @write slower than a synced plain write, @flush per batch ~1.8x with zstd, table arguments over TBL-1/TBL-2 (record lists through JSON); analyses and reviewed fixes in [../../performance/issues/](../../performance/issues/LIST.md); parallel's streaming fold-maps are quadratic for list and Str monoids ([stdlib-algorithms.md](../../performance/issues/stdlib-algorithms.md))
- [environment-deps.md](environment-deps.md): declared tools resolve through the inherited PATH; unknown package.yaml keys are ignored; a pin or snapshot cannot name a module outside the core org; init and make read a compiler variable differently; the strict make check misses cargo config and RUSTFLAGS
- [ifile-access.md](ifile-access.md): IFile index does not compile in Rust pools; projections after an IFile bracket decode whole elements; UNSOUND IFile and nexus IStream opens never check the element schema (STRM-1), stdin checked at first @next, one level per stream
- [binder-names.md](binder-names.md): runtime binder and pool-generated names share scope with user sources (C++ global C API and helpers; Rust prelude names at the crate root), manifold locals beside sourced names, C++ declares no reserved names (SRC-6) and its macros capture sourced names, R list misses `.morloc.*`, base R names user sources redefine, Python builtin sources resolving to pool globals; R runtime functions run interpreted outside the global environment
- [spec-and-docs.md](spec-and-docs.md): FMT-2/FMT-5 stale against SHM-6/12/13, SHM-6 zeroing side, cited tests that miss their rule (SHM-1, STATE-3, FORK-7, NET-3, PANIC-10, SLOT-16, SLOT-24), FORK-9 and once primitives, README model list, undocumented runtime variables, arch-build pages
- [schema-grammar.md](schema-grammar.md): a dead closure wire form and unused `SCHEMA_*` defines in morloc.h (removal is an ABI bump); a recursive list alias's schema
