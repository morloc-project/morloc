# Known issues

Each file holds a group of related issues, each framed against the model:
a spec item the code violates, or a gap in the spec. Evidence levels:
reproduced, read (verified by reading), speculative. Delete an entry when
it is solved, and a file when it is empty.

- [typecheck-output.md](typecheck-output.md): a list table column reaches code generation (TC-4 gap), locations lost after typechecking; `morloc typecheck` drops class constraints from signed exports; an unreduced field projection erases to a Nat placeholder
- [codegen-ownership.md](codegen-ownership.md): deciding a payload take walks the manifold once per candidate; a C++ `Try` from `r <- pull` is copied when unwrapped; a record field passed to a by-reference parameter is cloned first; a C++ conditional moves its result twice; an owned Rust loop local stepped through a `match` copies its rest each step; a nested Rust constructor pattern copies each inner field it tests; a Rust loop stepped by a function returning part of its argument copies the part; local and remote-worker segments share a plan key; C++ OWN-1 check opt-in only, do OWN-1..7 bind C++
- [codegen-copies.md](codegen-copies.md): C++ and Rust copy projections only read, move only at some keeping positions, copy crossing-closure captures and loop-carried setters; C++ copies unchanged loop slots; `map unpack` over a newtype copies each element
- [realization.md](realization.md): a 4-tuple in a do-block refused at realization (regression), let-bound function references priced from their cheapest home, values read across a boundary move for free, collapse and scoring disagree, merged signatures drop docstrings; COST-4..9 unimplemented (sizes, counts, self time; cost directives dropped); an argument computable in the caller is computed by a callback (open in COST-13)
- [codegen-limits.md](codegen-limits.md): generated R nests long guard chains too deeply for its parser; a C++ conditional needs a default constructor; a recursive C++ builder of a `data` with a Packable-mapped field does not build; a C++ pool may not declare an enum reached only as a `data` type's argument; Python/C++ `&&` chains nest (a ~100-operand Python chain fails to load, EMIT-4), Python per-call try/except re-raising RuntimeError (EMIT-3)
- [opaque-types.md](opaque-types.md): recursion over an opaque sourced type does not build (wire form demanded with no crossing); an opaque type crossing a boundary rejected with an internal message; an opaque value bound in a do-block split across pools does not build
- [kind-args.md](kind-args.md): a ground table row lowers as a value record: C++ showDefType counts a ground row as a `$N` slot, C++ templates miscount Rec-kinded (and Nat/Str-bound) parameters, a few walks still collect `@REC`; kind arguments render as empty text off the filtered lists, phantom-slot types skip the CPP-3/4/6 checks, wrong-arity `OpU` erases silently, any type variable is read as a Nat in deferred constraints
- [effect-boundaries.md](effect-boundaries.md): checker visits 3 of 7 boundaries (EBND-1), no check names its item, a label moves work into a suspension, a loop base returning a closure may be forced (speculative)
- [language-registry.md](language-registry.md): no single language object; plugin languages half work (needs a ruling: supported or deleted); dead registry fields (lang.yaml `cost:`) and functions
- [recursion-loops.md](recursion-loops.md): RECUR-2 tail calls kept as calls under `--debug`, on a labeled call, with a non-tail self-call beside them, or bound by `where`; dead effectful-loop gate
- [internal-checks.md](internal-checks.md): ~340 plain `zip`s truncate on a length mismatch instead of failing; fallbacks that turn an impossible shape into wrong output: ownership lowering skipped on a mismatch, `Tuple`-prefix name tests, unchecked intrinsic arguments, dropped selector leaves and effect variables, recursive types passed as wire form, misaligned closure captures, a lost variant constructor
- [internal-errors.md](internal-errors.md): internal errors a user program reaches (DIAG-1): an over-applied `@try`/`@write` (reproduced), `undefined` on a declaration overlapping a class term, a missing native mapping, function-typed or reserved-name fields, `$0` templates
- [compiler-state.md](compiler-state.md): `withModuleLock` drops state changes when its action throws; nothing bounds the compiler's heap residency
- [specialization.md](specialization.md): the in-place fallback expands every instance of every method; a method's use inside its own expansion becomes a back-edge; what only generic exports reach is checked only at a concrete use; a definition reached again through an instance is rejected as polymorphic recursion; each method use copies its elaboration
