# Known issues

Each file holds a group of related issues, each framed against the model:
a spec item the code violates, or a gap in the spec. Evidence levels:
reproduced, read (verified by reading), speculative. Delete an entry when
it is solved, and a file when it is empty.

- [typecheck-output.md](typecheck-output.md): a list table column reaches code generation (TC-4 gap), locations lost after typechecking; `morloc typecheck` drops class constraints from signed exports, prints a Nat variable as `a`
- [codegen-ownership.md](codegen-ownership.md): deciding a payload take walks the manifold once per candidate; a C++ `Try` from `r <- pull` is copied when unwrapped; a record field passed to a by-reference parameter is cloned first; a C++ conditional moves its result twice; an owned Rust loop local stepped through a `match` copies its rest each step; a nested Rust constructor pattern copies each inner field it tests; a Rust loop stepped by a function returning part of its argument copies the part; local and remote-worker segments share a plan key; C++ OWN-1 check opt-in only, do OWN-1..7 bind C++
- [codegen-copies.md](codegen-copies.md): C++ and Rust copy projections only read, move only at some keeping positions, copy crossing-closure captures and loop-carried setters; C++ copies unchanged loop slots; `map unpack` over a newtype copies each element
- [realization.md](realization.md): values a pool cannot hold refused or unchecked (COST-15), function arguments priced twice or not at all, collapse and scoring disagree, inlined arguments choose their implementation at the build site, normalized placement may abort; an argument computable in the caller is computed by a callback (open in COST-13)
- [codegen-limits.md](codegen-limits.md): a C++ conditional needs a default constructor; a C++ or Rust `data` with a Packable-mapped field does not build; C++ `?R` in pointer form other than a bare field, untested (CPP-6); a C++ pool may not declare an enum reached only as a `data` type's argument; a chain behind a node other than a conditional or let may nest per element, not reproduced (EMIT-5); record fields named by a C++/Rust keyword break the build
- [opaque-types.md](opaque-types.md): recursion over an opaque sourced type does not build (wire form demanded with no crossing); an opaque type crossing a boundary rejected with an internal message; an opaque value bound in a do-block split across pools does not build
- [kind-args.md](kind-args.md): a ground table row lowers as a value record: C++ showDefType counts a ground row as a `$N` slot, a few walks still collect `@REC`; wrong-arity `OpU` erases silently, any type variable is read as a Nat in deferred constraints
- [effect-boundaries.md](effect-boundaries.md): checker visits 3 of 7 boundaries (EBND-1), no check names its item, a label moves work into a suspension, a loop base returning a closure may be forced (speculative)
- [language-registry.md](language-registry.md): no single language object; plugin languages half work (needs a ruling: supported or deleted); dead registry fields (lang.yaml `cost:`) and functions; fork-pool languages hard-coded in the fold route
- [recursion-loops.md](recursion-loops.md): RECUR-2 tail calls kept as calls under `--debug`, on a labeled call, with a non-tail self-call beside them, or bound by `where`; dead effectful-loop gate
- [internal-checks.md](internal-checks.md): fallbacks that turn an impossible shape into wrong output: data-type parameters paired with arguments, unchecked intrinsic arguments, dropped selector leaves and effect variables, recursive types passed as wire form, misaligned closure captures, a lost variant constructor
- [internal-errors.md](internal-errors.md): internal errors a user program reaches (DIAG-1): an over-applied `@try`/`@write` (reproduced), `undefined` on a declaration overlapping a class term, a missing native mapping, function-typed or reserved-name fields, a form with no type list keeps `$N` in generated code; a program reaches the catch-all of `toNexusExpr`
- [compiler-state.md](compiler-state.md): `withModuleLock` drops state changes when its action throws; nothing bounds the compiler's heap residency
- [specialization.md](specialization.md): a method with one stuck use is expanded at every use; what only generic exports reach is checked only at a concrete use; each method use copies its elaboration; a key holding a generated Type variable is never shared (to measure)
- [install.md](install.md): a local git repo installs its working tree, installed_hash records the request not the fetched commit, the local and clone filters differ, auto-installed deps always use HTTPS, pins seen only by descendants
- [nominal.md](nominal.md): declared types reach code generation in several shapes, native identity by rendered text (NOM-1..6); mixed scopes in one `data` instance, the 64-instantiation bound, record update through a back-reference crashes, unweaveTypeF drops `data` arguments
- [wire-spelling.md](wire-spelling.md): values built from the wire spelled from serial forms: a recursive alias over kind parameters does not build
- [native-forms.md](native-forms.md): form lists not yet read as NATIVE-1 states: alias lists must follow declaration order, passes pair lists with parameters by position, C++ appends arguments to `$`-free forms
