# Known issues

Each file holds a group of related issues, each framed against the model:
a spec item the code violates, or a gap in the spec. Evidence levels:
reproduced, read (verified by reading), speculative. Delete an entry when
it is solved, and a file when it is empty.

- [aliases.md](aliases.md): order-dependent alias spelling (ALIAS-10), parallel unfolding mechanisms, an untested function-alias arity path
- [kinds-dimensions.md](kinds-dimensions.md): signature Nat variables are not rigid, unchecked newtype kinds, reserved-type kinds, operator classification, misplaced or renamed variables in kind diagnostics; Nat division by zero unreported (KIND-3), recursive newtypes through a container (NEWT-6), hand-written Packable bypassing NEWT-8, a Vector slice takes any length (DIM-3)
- [diagnostics-docs.md](diagnostics-docs.md): generated names in POLY-6 errors, `@mime` lost on structural aliases, stale manual docstring example, `match` branch errors reported as guard/if, inlined named calls missing from traces (DIAG-5), Rust `--debug` dumps no arguments, caught `--debug` failures may leak frames; conflicting native-form snippets mislabelled, `-hh` drops the blank line, REAL-3 rejection unnamed, R load failure printed twice, uncaught exceptions on non-UTF-8 source, bad package.yaml and unknown import (DIAG-1), `@render` reported as `@with`, `-0.0` loses its sign, an unbound newtype variable reported as a mismatch
- [typecheck.md](typecheck.md): an application through a type variable standing for a function, programs that typecheck and fail later, unlocated rejections, Rec self-equality, integer literal in a point-free section, stale manual table examples; complete nested patterns rejected as not exhaustive (PAT-3); a class variable only a constraint mentions is accepted, then defaulted to the sole instance or rejected far from the signature (POLY-6); short tuple patterns (PAT-1), mutual `where` recursion and value cycles crashing make (BIND-2), clause after a catch-all (SUM-3), local signature variables never instantiated (POLY-1), literal defaulting of constrained exports (SIG-5), EVAL-5 third answer, `[Int] ++ [Int]`
- [values.md](values.md): newtype native form dropped (NEWT-4), `data` comparison in R and C++ (SUM-5), numpy.int64 table column in Python, no rule against a Python source mutating a shared argument (EVAL-7); a `where` binding naming a parameter is rejected as cyclic; out-of-range index wrong in C++/R (COLL-3), `size` of Str differs, R drops Null map values (OPT-1), C++ nested optional (OPT-2), stale NUM-3, number rules with no item, `@schema` evaluates (INTR-4), unmapped record to a C++ source (NATIVE-4), realizer choice changes Int results (REAL-1 vs NUM-1)
- [programs.md](programs.md): single-export command name, argument numbering, `@check.path`/`@stdin` help, `@default` messages, unlocated CLI build errors, benchmark `{lang}`; two commands with one name (CMD-4), dotless import collides with a local file (MOD-7), `@stdin` on `?Str` (CLI-3), CLI-2 errors misplaced, epilogue trailing spaces (CLI-12), silently dropped `@stdin`/`@arg`, program rules with no item, a dotted import of a multi-module file (MOD-1, MOD-5)
- [manual.md](manual.md): manual text that contradicts a spec item and needs a ruling, or a new example
- [typeclasses.md](typeclasses.md): signature in an instance body crashes the compiler, catch-all fallthrough depends on instance body (CLS-12), unchecked class obligations and superclasses (CLS-5), a method used at another type inside its own instance calls that instance (CLS-2, #160), sourced constrained functions such as `sort` ignore the instance; an instance missing a method reported as no instance
- [records.md](records.md): design decision pending: are inline (anonymous) record types legal?; a generic Rust struct cannot carry a phantom parameter, a phantom parameter still needs a Python form when a Python function takes the record; TEQ-4 vs field-order rule, record literal needs a Py/R form (NATIVE-3), recursive records SUM-4 vs ALIAS-7, extra JSON keys accepted
- [tables.md](tables.md): a table cannot be streamed; it is loaded whole before the command runs
- [interfaces.md](interfaces.md): CLI, daemon HTTP/LP, MCP and front end disagree on commands served, argument decoding and defaults, `@default`, render bytes, failure classes, discovery, limits and eval gating (IFACE)
- [labels.md](labels.md): unmeasured stage work of a labeled partial application, constants a labeled function computes evaluated outside its hooks; cache entries are per call site (ANN-4)
- [host-calls.md](host-calls.md): a call stopping at an `rsize` group boundary with groups left is called flat (HOST-3); a point-free reader over a Rust function fails when Python both collects and writes it (WIRE-6); a point-free source over a list of sources followed by a Python call is an internal error (lambda language check); invalid `rsize` accepted until called (HOST-3), two directive spellings
- [syntax.md](syntax.md): blocks opened mid-line are not closed by `,` `;` `:` `where`; a missing `let` in `do { y = 1; ... }` is reported as a record; interpolated triple-quoted strings not dedented (LIT-5), lexical gaps (`deriving` keyword, `+--`, `12abc`, `-NaN`, infix definitions, `()` pattern)
- [effects.md](effects.md): suspension in a record rejected (EFF-2), `do` tail run by expected type (EFF-4), `!` outside a do-block (EFF-7 vs manual), effect rules with no item, malformed foreign `Try` decoded silently
- [guests.md](guests.md): Futhark check takes any applied type as a scalar (GUEST-2/3), an unsourced `bool` entry breaks its file, unnamed rejections
